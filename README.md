# CampusFlow

A mobile-first student dashboard concept for timetables, attendance, deadlines, and campus life. It uses a warm editorial interface, glass-like cards, responsive layout, and a clear check-in interaction with a screen-reader announcement.

## Run locally

Open `index.html` in a browser, or serve this folder with any static-file server. No dependencies or build step are needed.

## Product decisions

- One calm “next up” action rather than a dense dashboard
- Visible agenda times, compact deadline alert, and generous touch targets
- Keyboard-accessible controls and responsive single-column mobile view
